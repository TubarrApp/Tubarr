Rules File

Path to a config file (YAML/TOML/JSON) defining custom scraping selectors for additional sites. Applies to all channels. Clear the path to go back to built-in defaults only.

Example File: example-scrape-rules.toml  |  Documentation: site-rules-documentation.html

Recognized 'string' fields:
title, description, thumbnail, direct_video_url

Recognized 'full date' fields:
upload_date, release_date, date

Recognized 'year' fields:
year, release_year

Other fields are added into the metadata JSON as-is, without special handling.
