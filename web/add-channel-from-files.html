Absolute path to a YAML (.yaml/.yml), TOML (.toml) or JSON (.json) configuration file containing channel settings.

Absolute path to a directory containing multiple channel configuration files. All valid config files will be processed.

Configuration File Format

Your config file(s) should contain all necessary channel settings including:

  • Channel name
  • Channel URLs
  • Video and JSON directories

Directory mode: All .yaml, .yml, .toml and .json files in the directory will be processed. Each file should define one complete channel configuration.
