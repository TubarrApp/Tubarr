Web Interface Access

Login

Signed in as . Changing the login signs out every other browser.

This login is set by TUBARR_WEB_PASSWORD, so a change made here is replaced when Tubarr restarts.

API Key

Scripts can send this in an X-Api-Key header instead of logging in.

Login Mode

Who has to log in. Saved with Save access settings below. A forgotten password can be reset with tubarr auth reset, or TUBARR_WEB_PASSWORD.

Set by TUBARR_WEB_AUTH (or --web-auth), so it can't be changed here.

Anyone who can reach Tubarr can control it, so only use this behind a reverse proxy with its own login.

Skip Login For

Devices at these addresses don't need to log in. One address or range per line, e.g. 192.168.1.0/24 for every device on a typical home network.

Docker: everything from the host computer arrives from the Docker network (e.g. 172.17.0.1), so listing the Docker range (172.16.0.0/12) turns the login off for everyone who can reach Tubarr.

Reverse proxy (e.g. Nginx Proxy Manager, Caddy, Traefik): add the proxy's address under Trusted Proxies below. Until you do, everyone coming through the proxy has to log in, even from the addresses listed here. If the proxy runs on the same machine as Tubarr, it must pass on each visitor's address (the X-Forwarded-For header). Otherwise every visitor looks like localhost, and with "Required, except from localhost" nobody has to log in.

Allowed Hostnames

Names this server is reached by without a login, besides localhost, IP addresses and its own hostname (e.g. tubarr.home). Others are refused, so other websites can't reach Tubarr through your browser.

Trusted Proxies

Reverse proxies whose X-Forwarded-For header gives the real client address. Leave empty without a reverse proxy.

HTTPS

Serves the web interface over HTTPS instead of HTTP, applied when Tubarr restarts. Uses a self-signed certificate unless a certificate is set below, so browsers show a warning the first time.

HTTPS is currently off. Serving the self-signed certificate. Serving the certificate below. Restart Tubarr to apply the change.

Set by --web-https or TUBARR_WEB_HTTPS, change it there.

Certificate

Path to a PEM certificate on the Tubarr machine, either with the key in the same file or with a separate key file. Changes apply to new connections without a restart.

Set by --web-tls-cert or TUBARR_WEB_TLS_CERT, change it there.
