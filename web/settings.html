Web Interface Access

Login is turned off (--web-auth none). Anyone who can reach Tubarr can control it, so only use this behind a reverse proxy with its own login.

Login

Signed in as . Changing the login signs out every other browser.

API Key

Scripts can send this in an X-Api-Key header instead of logging in.

Skip Login For

Requests from these addresses need no login. One IP or CIDR range per line (e.g. 192.168.1.0/24). In Docker, requests from the host arrive from the Docker gateway (e.g. 172.17.0.1), so adding 172.16.0.0/12 would skip login for everything reaching the port.

Allowed Hostnames

Names this server is reached by without a login, besides localhost, IP addresses and its own hostname (e.g. tubarr.home). Others are refused, so other websites can't reach Tubarr through your browser.

Trusted Proxies

Reverse proxies whose X-Forwarded-For header gives the real client address. Leave empty without a reverse proxy.

HTTPS

Serves the web interface over HTTPS instead of HTTP, applied when Tubarr restarts. Uses a self-signed certificate unless a certificate is set below, so browsers show a warning the first time.

HTTPS is currently off. Serving the self-signed certificate. Serving the certificate below. Restart Tubarr to apply the change.

Set by --web-https or TUBARR_WEB_HTTPS, change it there.

Certificate

Path to a PEM certificate on the Tubarr machine, either with the key in the same file or with a separate key file. Changes apply to new connections without a restart.

Set by --web-tls-cert or TUBARR_WEB_TLS_CERT, change it there.
